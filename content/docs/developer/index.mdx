## Non-negotiables

- Money is `BigInt` minor units. Rates are integers scaled by 1,000,000. Margins, VAT and taxes are
  basis points.
- The pricing engine is pure, and VAT is calculated on markup only.
- Line prices add up exactly to the total in every presentation layout.
- Issued documents are frozen snapshots.
- Payments are append-only; corrections are reversing entries.
- Every write is a server action: capability check, Zod validation, write and audit in one
  transaction.
- Contacts and passengers are archived, never deleted once referenced.
- Passport data is never stored.

## Working on the app

```bash
npm install
npm run db:generate
npm run db:deploy
npm run db:seed
npm run dev
```

Then:

```bash
npm run typecheck
npm run lint
npm test
npm run build
```

See [testing](/docs/developer/testing) and [contributing](/docs/developer/contributing) for the full
workflow.
